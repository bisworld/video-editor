# Underwater AI Video Cutter & Enhancer 🌊

Локальное веб-приложение на **Python 3 + Streamlit** для автоматического монтажа подводного видео.
Обработка полностью офлайн: **OpenCV** (анализ, CLAHE, детекция людей) + **MoviePy** (склейка).
Сторонние API и ключи не используются.

## Возможности

- Отбор лучших фрагментов по резкости (Laplacian), рыбам (контуры) и пейзажу (HSV)
- Исключение кадров с людьми (HOG + Haar face cascade)
- Улучшение подводного цвета через CLAHE
- Фильтр мутных / смазанных кадров
- Экспорт в оригинальном, 1080p, 720p или вертикальном 1080×1920 (Shorts/Reels)

## Требования

- Ubuntu (или другой Linux)
- Python 3.10+
- FFmpeg (подтягивается через `imageio-ffmpeg`; системный `ffmpeg` тоже желателен)

## Установка и запуск (Ubuntu + venv)

```bash
# 1. Системные пакеты для venv и MoviePy
sudo apt update && sudo apt install python3-venv python3-pip imagemagick ffmpeg

# 2. Виртуальное окружение
python3 -m venv venv

# 3. Активация
source venv/bin/activate

# 4. Зависимости
pip install --upgrade pip && pip install -r requirements.txt

# 5. Запуск интерфейса
streamlit run app.py
```

Откройте в браузере адрес, который покажет Streamlit (обычно `http://localhost:8501`).

### Деактивация окружения

```bash
deactivate
```

## Использование

1. В боковой панели задайте длину ролика, разрешение, приоритет сюжета и фильтры.
2. Загрузите видео (MP4 / MOV / AVI).
3. Нажмите **Запустить обработку**.
4. Дождитесь шагов анализа и склейки.
5. Посмотрите превью и скачайте результат кнопкой **Скачать готовое видео**.

## Примечания

- Работайте **только внутри `venv`**, чтобы не смешивать системные пакеты.
- Детекция людей (HOG) замедляет анализ на длинных роликах — это ожидаемо.
- Если фрагментов не найдено, снизьте «Фильтр мутных кадров» или отключите «Исключить людей».
